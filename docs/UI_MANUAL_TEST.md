# UI 수동 테스트 (실제 Chrome · Verse8)

자동화 브라우저(앱 미리보기 창)는 포인터 잠금·전체 화면을 막아서(`featurePolicy` pointer-lock = false, `requestFullscreen` 응답 없음)
아래 항목은 실제 Chrome에서 확인한다. 콘솔에 `[pointer-lock]` 기록(거부 횟수·임베드 여부·정책·마지막 해제 이유)이 남는다.

## 포인터 잠금 · 일시정지 (2026-10-23)

| # | 절차 | 기대 결과 |
|---|------|-----------|
| 1 | Verse8 일반 화면에서 연습전 시작 | 마우스가 고정되면 바로 카운트다운. 못 잡으면 "게임 화면을 클릭해 조준을 시작하세요" 안내(일시정지 아님) |
| 2 | 안내에서 `게임 화면 활성화` 또는 뒤 화면 클릭 | 고정 성공 → 안내 사라짐, 타이머 진행 |
| 3 | 전투 중 ESC | "일시정지" (이유 문구 없음). `계속하기` → 바로 고정·재개. ESC 직후 1초 안에 누르면 브라우저가 거부 → 안내 화면에 "1초 뒤 다시" |
| 4 | 전투 중 다른 창 클릭(Alt+Tab) | "일시정지" + "게임 화면 밖을 눌러서 멈췄어요" |
| 5 | 전투 중 다른 탭으로 이동 후 복귀 | "일시정지" + "다른 탭·창으로 이동해서 멈췄어요" |
| 6 | 고정이 계속 거부되는 임베드 화면 | 안내 화면에 이유 + `확장 화면으로 전환` 버튼 (팝업 반복 없음) |
| 7 | 연습전 일시정지 중 | 타이머·봇 정지, 재개 뒤 일시정지 화면 DOM 숨김(`.lb-pause[hidden]`) |
| 8 | 콘솔 `__game.input.kbm.lastUnlock` / `lockErrors` | 3~5번 상황마다 esc · blur · hidden · error 로 구분됨 |

## 확장 화면 상태

| # | 절차 | 기대 결과 |
|---|------|-----------|
| 1 | Verse8 바깥 확장 버튼으로 확장한 뒤 첫 매치 시작 | "확장 화면으로 플레이할까요?" 안 뜸 |
| 2 | 확장 상태에서 설정 > 일반 > 화면 | 스위치 `켬` |
| 3 | 바깥에서 확장 해제 | 스위치 즉시 `끔` (창 크기 변화 감지) |
| 4 | 일반 화면에서 스위치 켬 | 게임 안 전체 화면, 거부되면 1.5초 안에 이유 한 줄 |
| 5 | 바깥 확장 상태에서 스위치 끔 | "Verse8 화면의 확장 해제 버튼으로…" 안내 |

판단 기준: Verse8이 확장 상태를 알려 주는 API·메시지가 없어(SDK·문서 확인) 게임 창이 화면의 92%×85% 이상이거나 게임 안 전체 화면이면 확장으로 본다.
최대화한 일반 브라우저 창도 확장으로 보일 수 있음(넓은 화면이라 권유가 필요 없는 경우).

## VXShop 유료 캐릭터 (SHONI·BAM, 2026-10-23)

대시보드 등록값: `character-shoni` / `character-bam`, 300 VX, Lifetime Limit 1, Active.
Verse8 preview(`agent8-container.` 호스트)는 SDK가 상품을 PREVIEW 단계로 조회 → preview·production 각각 상품이 보이는지 확인.
실제 VX 결제는 소유자 승인 뒤에만 진행.

| # | 절차 | 기대 결과 |
|---|------|-----------|
| 1 | Verse8 게임 화면에서 상점 열기 | 두 캐릭터 가격 = 대시보드 가격, 구매 버튼 켜짐 (상품 미등록이면 꺼짐 + "아직 판매 중인 상품이 아니에요") |
| 2 | 구매 버튼 → 결제창에서 닫기(취소) | "결제를 취소했어요 · 캐릭터는 지급되지 않았어요", 잠금 유지 |
| 3 | 구매 완료 | "구매 확인 중…" → 서버 보유 반영되면 "구매 완료!", 잠금 해제, 장착 가능 |
| 4 | 새로고침 · 다른 기기 같은 계정 | 보유 유지 (서버 글로벌 사용자 상태 chars), 저장해 둔 유료 캐릭터 자동 장착 |
| 5 | 이미 산 상품 | 버튼 대신 "✓ 보유 중 / 장착하러 가기" (Lifetime Limit 1로 결제창도 막힘) |
| 6 | 서버 로그 | `purchase_granted` (중복이면 `purchase_duplicate`, 이미 보유면 `purchase_already_owned`, 모르는 상품 `purchase_unknown_product`) |
| 7 | 미보유 계정이 개발자 도구로 white/black 전송 | 로비는 BLUE로 표시, 매치 hello는 `charDenied: not_owned` (캐릭터 안 바뀜) |
