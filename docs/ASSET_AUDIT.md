## 게임 로직 문제 (에셋과 무관, 수정됨)
- **캐릭터 근접 시 점무늬:**
  - 원인: 직전 수정에서 넣은 alphaHash(디더 투명). 카메라가 피벗 0.9m 이내면 opacity 0.3을 alphaHash로 표현해 픽셀 단위 무작위 점이 생김. 멀어지면 opacity 1이라 사라짐.
  - 수정 (`src/render/MeshFader.ts`):
    - 같은 지오메트리·스켈레톤의 깊이 전용 사전 패스를 먼저 그리고, 부드러운 알파로 가장 앞 표면만 그림 → 점무늬도 안쪽 면 비침도 없음.
    - 카메라가 몸 경계 상자 0.12m 이내(안쪽 포함)면 색은 그리지 않고 그림자만 남김.
    - opacity 1이면 머티리얼 원래 값으로 복원. 아바타 전용 복제 머티리얼이라 GLB 원본은 그대로.
- **벽을 등지면 카메라가 캐릭터 안으로:**
  - 측정: 어깨 쪽과 뒤쪽이 모두 벽에 막혀 카메라가 머리 중심에서 0.30m(몸 경계 안)까지 붙음. 정상적인 충돌 결과라 가림 처리로 해결.
  - `LocalPlayerOcclusion`: 로컬 플레이어만, 몸·무기 따로 거리 기반 페이드.
  - 카메라 충돌 보강: 충돌 지점 앞 2cm 여유(이전엔 겹친 채 다음 검사가 시작돼 벽에서 7.9cm까지 붙음 → 지금 0.20m 유지), 어깨 오프셋도 빠르게 당기고 천천히 복귀.
  - 남은 점: 카메라를 빠르게 돌리다 벽이 끼어들면 관통 방지를 위해 한 프레임에 크게(측정 최대 1.3m) 당겨짐. 일반 TPS와 같은 방식이지만 순간 이동처럼 느껴질 수 있음.
- **재장전 때 "몸속이 보임":**
  - 재장전이 ADS를 해제하면 카메라가 스코프 → TPS로 돌아오는 0.2초 동안 캐릭터가 반투명으로 다시 나타남.
  - 반투명은 깊이를 쓰지 않아 팔·몸통 안쪽 면이 겹쳐 비침. 재장전 자체는 카메라·FOV를 바꾸지 않음(측정: FOV 70, 거리 2.71m 고정).
  - 1차 수정(alphaHash)은 근접 점무늬를 만들어 깊이 사전 패스 방식으로 교체 (위 항목).
- **Shift를 놓아도 조깅 유지:** 걷기↔조깅 속도 히스테리시스의 해제 기준(3.1 m/s)이 걷기 속도(3.4 m/s)보다 낮아 조깅에서 빠져나오지 못함. 애니메이션을 컨트롤러의 현재 달리기 상태(Shift + 앞 입력 + 지상)로 결정하도록 변경, 전환 시 발 위상 맞춤.
- **발이 2cm 떠 보임:** Rapier 캐릭터 컨트롤러가 장애물과 0.02m 간격을 유지하는데 렌더링이 이를 빼지 않았음 → 발 위치 = 캡슐 중심 − (절반 높이 + 반지름 + 0.02).
- **달리기 위치 튐:**
  - 지상에서 매 스텝 −1 m/s로 아래로 밀어 캡슐이 보호 간격 안으로 파고듦.
  - Rapier 기본 복원(1e-4 m/스텝)이 느려 이동량 0 스텝이 섞임. 코드가 실제 이동량으로 속도 전체를 깎아 순간 정지 → 재가속, 애니메이션 idle↔run 깜빡임.
  - 수정: 지상 수직 속도 0 + snap-to-ground, nudge 0.004, 벽 법선 성분만 제거, 달리기 FOV 보간, 걷기↔조깅 히스테리시스.
  - 결과: 걷기→달리기→방향 전환→점프→걷기→슬라이딩 연속 테스트에서 오작동 멈춤 0, 역방향 프레임 0.
  - 루트 모션: 모든 클립의 Hips 이동이 2cm 미만이라 이동과 충돌하지 않음.

검증 안 됨 / 미확인:
- 애니메이션 전환 순간의 스키닝 깨짐을 프레임 단위로 보지 않았다 (정지 화면 몇 장만 확인).
- `Death01` 재생 중 IK를 끄므로 총은 손을 따라가지만, 쓰러진 자세에서 총이 몸에 파묻히는지는 미확인.
- 실제 모바일 기기 성능 미측정.

### ADS 현재 상태 (2026-10-20)
- 하이브리드 ADS(스코프 뒤 카메라)와 렌즈 확대 화면(RenderTexture)은 시야 방해로 제거.
- 라이플 ADS(`shoulder`): 오른쪽 어깨 카메라에서 캐릭터 뒤 거의 중앙(오른쪽 0.1m, 뒤 0.8m, 머리 높이)으로 이동하며 1.4배 확대. 전투 자세 몸 비틀기(40°)도 ADS 중에는 풀어 총구가 중앙 쪽.
- ADS 중 표시: 로컬 캐릭터의 모든 스킨 메시를 `visible=false`(머리·몸통·팔·손·다리 전부), 라이플만 표시. 본 애니메이션·무기 위치·사격 판정은 숨김과 무관하게 계속 갱신.
  - 이전의 정점 마스크(팔·손만 남김) 방식은 손이 총 주변에 튀어나오고, ADS 해제 때 마스크 부분을 반투명으로 되살리는 경로가 깊이 사전 패스에서 빠져 머리 안쪽 면이 비치는 원인이었음 → 새 방식으로 대체 확인 후 삭제.
- ADS 해제 후 표시: ADS 상태가 아니라 최종 카메라 위치 기준 (`LocalPlayerOcclusion`).
  - 카메라와 몸 경계 상자 거리 < 숨김 0.15m + near 평면 여유면 숨김. 숨긴 뒤에는 0.30m + near 여유 이상 멀어져야 다시 표시 시작, 0.60m + 여유에서 완전 불투명 (히스테리시스).
  - near 평면 여유 = 카메라에서 near 평면 모서리까지 거리 (지금 화각에서 약 0.087m).
  - 다시 나타나는 페이드는 깊이 사전 패스 알파 유지: 사전 패스를 끄고 투명도 0.5로 비교해 보니 모자 챙·얼굴 뒤쪽 면이 겹쳐 비침 (화면 확인). 불투명·숨김 상태에서는 사전 패스를 그리지 않음.
- 측정 (729프레임: ADS 켜기/끄기, 10회 빠른 반복, 회전하며 해제, 이동하며 해제, 벽 등지고·마주 보고 해제, ADS 중 사격): 몸이 경계 0.38m 안에서 그려진 프레임 0 (최소 0.396m), ADS 중 몸 표시 0, ADS 중 총 사라짐 0, 카메라 벽 진입 0, ADS 26회 전환 외 표시 깜빡임 없음.

## 근접 공격 몸 방향 (2026-10-20)

- 판정 방향도 몸 정면 기준으로 변경 (사용자 결정): `WeaponFrame.bodyForward`(몸 yaw의 수평 정면)를 근접 판정·조준선 빨강 예측에 사용. 사거리 1.6m(판정 영역 표면까지)·반각 55°·데미지 40·판정 시점 0.17s는 그대로. 총기 판정은 카메라 기준 그대로.
- 측정(노랑 표적, 공격 1회마다 근접 결과 직접 기록, 봇 사격 0회 확인):

  - 이동하며: W 전진·S 후진(카메라 쪽으로, 대상이 이동 방향)·A/D 옆·W+D 대각 → 몸이 이동 방향 0°, 모두 명중 40. 대상을 보며 S로 멀어지면(몸이 대상 반대) 빗나감
